# Shadow Filter H265 用户使用说明书 (筛选应用)

## 1. 产品简介
本系统是一款集成了 AI 智能筛选与双编码推流的视频处理应用。它能接入 4 路模拟摄像头，实时通过 AI 算法筛选出包含目标的画面（Filter 流），同时提供 4 路摄像头的全景监控画面（Monitor 流）。所有视频流均同时提供 H.264 和 H.265 两种编码格式，并支持 ONVIF 协议，可无缝接入各类 NVR 录像机或 VMS 平台。

## 2. 快速启动

### 2.1 环境准备
确保已连接 4 个模拟摄像头，并已安装相关依赖环境。

### 2.2 启动命令
在项目根目录下运行：
```bash
python cam_filter.py
```
*如需公网访问（配合 FRP），请参考下文“远程访问参数”。*

启动成功后，控制台将输出 ONVIF 服务地址列表，且不再输出冗余的调试日志。

## 3. 视频流接入指南

本系统提供 4 个独立的 ONVIF 服务端口，分别对应不同的画面和编码格式。请根据您的 NVR 或播放器支持情况选择添加。

### 3.1 ONVIF 设备列表

| 设备名称 (逻辑) | 端口 | 编码 | 画面内容 | 分辨率 | 
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Device A** | **18000** | H.264 | **筛选画面 (Filter)** | 720x576 | 
| **Device B** | **18001** | H.264 | **四分屏监控 (Monitor)** | 720x720 |
| **Device C** | **19000** | H.265 | **筛选画面 (Filter)** | 720x576 | 
| **Device D** | **19001** | H.265 | **四分屏监控 (Monitor)** | 720x720 |

### 3.2 添加至 NVR (录像机)
1.  进入 NVR 的“添加设备”或“自定义添加”界面。
2.  **IP 地址**: 填写运行本软件的服务器 IP (如 `192.168.1.100` 或公网映射 IP)。
3.  **端口**: 填写上述表格中的对应端口 (如 `18000`)。
4.  **协议**: 选择 `ONVIF`。
5.  **用户名**: `shadow`
6.  **密码**: `password147`
7.  点击“添加”或“刷新”，NVR 应能自动识别设备并出图。

### 3.3 RTSP 直接播放地址
如果您不使用 ONVIF，也可以直接通过 RTSP 播放器 (VLC, ffplay, PotPlayer) 拉流。
**注意：流地址必须包含鉴权信息（用户名:密码）。**

*   **H.264 流 (推荐)**:
    *   监控: `rtsp://shadow:password147@IP:8554/monitor_h264`
    *   筛选: `rtsp://shadow:password147@IP:8554/filter_h264`
*   **H.265 流**:
    *   监控: `rtsp://shadow:password147@IP:8554/monitor_h265`
    *   筛选: `rtsp://shadow:password147@IP:8554/filter_h265`
*(注：请将 `IP` 替换为运行程序的服务器实际 IP 地址)*

## 4. 详细启动参数说明

您可以通过命令行参数自定义系统行为：

### 基础配置
*   `--model [PATH]`: 指定 YOLO 模型路径 (默认: `./best.pt`)
*   `--conf [FLOAT]`: AI 推理置信度阈值 (默认: `0.7`)
*   `--batch-size [INT]`: AI 推理批处理大小，显存允许时越大越快 (默认: `32`)
*   `--output [DIR]`: 视频保存目录 (默认: `optimized_videos`)
*   `--save`: 启用视频录制功能 (默认: 关闭)

### 流媒体与网络
*   `--no-rtsp`: 禁用 RTSP 推流功能 (默认: 开启)
*   `--public-ip [IP]`: 设置对外宣告的公网 IP 地址，用于生成 ONVIF/RTSP 播放地址 (默认: `117.72.39.181`)
*   `--public-rtsp-port [PORT]`: 设置对外宣告的 RTSP 端口 (默认: `8554`)
*   `--public-onvif-monitor-port [PORT]`: 设置对外宣告的 ONVIF Monitor 端口 (默认: `18000`)
*   `--public-onvif-filter-port [PORT]`: 设置对外宣告的 ONVIF Filter 端口 (默认: `18001`)

### 图像处理与增强
*   `--no-denoise`: 禁用降噪处理 (默认: 开启中值降噪)
*   `--denoise-method [METHOD]`: 指定降噪算法 (默认: `median`)
    *   `median`: 中值滤波，适合去除椒盐噪声/雪花点
    *   `gaussian`: 高斯滤波
    *   `nlm`: 非局部均值滤波 (效果好但较慢)
    *   `gaussian_nlm`: 组合滤波
    *   `wavelet`: 小波降噪
*   `--no-temporal`: 禁用时域亮度稳定控制 (默认: 开启)
*   `--temporal-target [FLOAT]`: 时域稳定目标亮度均值 (0-255, 默认: `85.0`)
*   `--temporal-alpha [FLOAT]`: 时域平滑系数，越小变化越平滑 (0.01-1.0, 默认: `0.01`)

### 高级配置 (环境变量)
系统支持通过环境变量覆盖默认的 RTSP 鉴权信息：
*   `RTSP_READ_USER`: RTSP/ONVIF 拉流用户名 (默认: `shadow`)
*   `RTSP_READ_PASS`: RTSP/ONVIF 拉流密码 (默认: `password147`)
*   `RTSP_PUBLISH_USER`: RTSP 推流用户名 (默认: `shadow`)
*   `RTSP_PUBLISH_PASS`: RTSP 推流密码 (默认: `password147`)

**注意**:
*   系统默认尝试连接 `/dev/video0` 至 `/dev/video3` 这 4 个摄像头设备。如需修改，目前需调整代码中的 `camera_devices` 列表。

**示例**:

```bash
# 修改鉴权密码启动 (注意：需同时修改读写密码以确保鉴权一致)
export RTSP_READ_PASS=mysecurepass
export RTSP_PUBLISH_PASS=mysecurepass
python cam_filter.py
```

```bash
# 指定公网 IP 并开启录制
python cam_filter.py --public-ip 192.168.1.50 --save

# 使用高置信度阈值和特定模型
python cam_filter.py --conf 0.85 --model ./yolov8n.pt
```

## 5. 故障排查

*   **Q: NVR 提示 "400 Bad Request"?**
    *   A: 请确认您添加的端口与 NVR 支持的编码格式匹配。例如，若 NVR 不支持 H.265，请勿添加 19000/19001 端口。
*   **Q: 画面颜色异常或有条纹?**
    *   A: 这通常是分辨率不匹配导致的。Monitor 流已固定为 720x720，Filter 流为 720x576。请确保播放器未强制拉伸画面。
*   **Q: 提示 "404 Not Found"?**
    *   A: 检查 MediaMTX 是否正常启动，或者等待几秒钟让 FFmpeg 推流初始化完成。
*   **Q: 播放时提示 "401 Unauthorized"?**
    *   A: 请检查 RTSP 地址中是否包含了正确的用户名和密码 (`shadow:password147`)。
