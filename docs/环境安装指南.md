# 环境安装与运行指南

## 1. 基础环境要求
- **操作系统**: Linux (推荐 Ubuntu 20.04/22.04)
- **Python**: 3.10+ (建议使用 Conda 管理环境)
- **硬件**:
  - 摄像头: 支持 V4L2 协议的采集卡/摄像头 (可见 `/dev/video*`)
  - GPU: NVIDIA 显卡 (推荐, 用于加速 YOLO 推理与 NVENC 编码)
- **软件依赖**:
  - FFmpeg (必须支持 NVENC 以获得最佳性能)
  - CUDA Toolkit (对应 PyTorch 版本)

---

## 2. 系统级依赖安装

### 2.1 安装基础工具与 FFmpeg
```bash
sudo apt-get update
sudo apt-get install -y ffmpeg v4l-utils libssl-dev git build-essential
```

### 2.2 验证摄像头
确保摄像头设备已正确识别：
```bash
ls -l /dev/video*
v4l2-ctl --list-devices
```

---

## 3. Python 环境配置

推荐使用 Miniconda 创建独立环境，避免依赖冲突。

### 3.1 创建 Conda 环境
```bash
# 创建名为 shadow_env 的环境，指定 Python 3.10
conda create -n shadow_env python=3.10 -y
conda activate shadow_env
```

### 3.2 安装 PyTorch
根据您的 CUDA 版本选择合适的安装命令（以下以 CUDA 12.1 为例）：
```bash
conda install pytorch torchvision pytorch-cuda=12.1 -c pytorch -c nvidia -y
```
*注：若无 NVIDIA 显卡，可安装 CPU 版本，但推理速度会受影响。*

### 3.3 安装项目依赖
在项目根目录 (`/home/jiangfeng/shadow_filter_h265`) 下执行：
```bash
pip install -r requirements.txt
```

---

## 4. MediaMTX (RTSP 服务器) 配置

本项目集成了对 MediaMTX 的自动管理，但首次运行需准备程序包。

### 4.1 下载与放置
1.  访问 [MediaMTX Releases](https://github.com/bluenviron/mediamtx/releases)。
2.  下载适用于 Linux 的压缩包 (例如 `mediamtx_v1.x.x_linux_amd64.tar.gz`)。
3.  将下载的文件重命名为 `mediamtx.tar.gz`。
4.  将文件放置在项目的 `rtsp_server/` 目录下。

**目录结构示例**:
```
shadow_filter_h265/
├── cam_filter.py
├── requirements.txt
└── rtsp_server/
    └── mediamtx.tar.gz  <-- 放置在这里
```

*系统首次启动时会自动解压并配置该文件。*

---

## 5. 运行与验证

### 5.1 启动筛选应用
```bash
# 激活环境
conda activate shadow_env

# 启动主程序
python cam_filter.py
```

### 5.2 验证运行状态
1.  **控制台日志**: 应显示 "ONVIF Server 启动成功" 及各路流的 RTSP 地址。
2.  **RTSP 播放**:
    使用 VLC 或 ffplay 播放测试（替换 IP 为实际地址）：
    ```bash
    ffplay -rtsp_transport tcp rtsp://shadow:password147@<IP>:8554/filter_h264
    ```

### 5.3 常见问题排查
*   **权限错误 (Permission denied)**: 确保当前用户有权访问 `/dev/video*` 设备，或尝试 `sudo chmod 666 /dev/video*`。
*   **MediaMTX 启动失败**: 检查 `rtsp_server/mediamtx.tar.gz` 是否存在且完整；检查 `8554` 端口是否被占用。
*   **ImportError: libGL.so.1**: 若缺失 OpenCV 依赖，执行 `sudo apt-get install libgl1`。
