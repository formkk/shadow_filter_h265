用户使用说明书（采集-分割-标注-平衡-增量训练-评估）

一、准备工作

  • 确认已安装依赖：pip install -r requirements.txt
  • 摄像头已连接并出现在 /dev/video0-3（如数量不同，采集脚本可调整）。
  • GPU：请确保 CUDA 驱动正常。

二、采集

脚本：continuous_camera_capture.py - 功能：从多个摄像头持续拍照，保存到目录。 - 默认参数（在脚本中主函数）： - output_dir="continuous_photos"：输出目录 - duration=30：持续拍照 30 秒 - interval=0.02：每 0.02 秒拍一张 - 运行：

python continuous_camera_capture.py
  • 输出：在 continuous_photos/ 生成 camera_<id>_<timestamp>.jpg。

提示：如需自定义摄像头索引、时长、间隔，可修改脚本初始化参数或改写为命令行参数版本。

三、图像分割

脚本：split_images_for_training.py - 功能：将大图分割为 224x224 瓦片，用于分类训练。 - 常用参数： - --input_dir：输入目录，如 ./continuous_photos - --output_dir：输出目录，建议为 ./training_tiles - --tile_size：瓦片大小，默认 224 - --class_name：类别名；若未标注前，建议使用 unknown - 示例：

python split_images_for_training.py --input_dir ./continuous_photos --output_dir ./training_tiles --tile_size 224 --class_name unknown
  • 输出：training_tiles/unknown/ 下生成瓦片。

四、标注与移动到分类目录

对training_tiles/unknow 内所有图片进行人工筛选. - 浏览training_tiles/unknown/目录，并将图片人工辨别后，根据图片类别分别移动至 training_tiles/zhedang/ 或 training_tiles/zhengchang/ 目录内， - 完成后删除training_tiles/unknown/子目录。

五、构建训练/验证集结构

脚本：prepare_dataset_split.py - 功能：将 training_tiles/ 中的已分类瓦片按比例拆分到 training_tiles_dataset/train 与 val。 - 常用参数： - --input_root：输入根目录，如 ./training_tiles - --output_root：输出根目录，如 ./training_tiles_dataset - --train_ratio：训练集比例，默认 0.8 - --seed：随机种子，默认 42（保证可复现） - --move：移动文件而非复制（默认复制） - 示例：

python prepare_dataset_split.py --input_root ./training_tiles --output_root ./training_tiles_dataset --train_ratio 0.8 --seed 42
  • 输出：生成 training_tiles_dataset/train 与 val 下的两个类别子目录。

六、数据平衡（训练集）

脚本：balance_dataset.py - 功能：对 train 或 val 集进行过采样/欠采样，建议仅对 train 进行过采样。 - 常用参数： - --input_dir 与 --output_dir：都指向 ./training_tiles_dataset - --method：oversample 或 undersample - --split：train 或 val - 示例：

python balance_dataset.py --input_dir ./training_tiles_dataset --output_dir ./training_tiles_dataset --method oversample --split train
  • 输出：在 training_tiles_dataset/train/<class> 下增加增强样本。

提示：为避免评估偏差，val 集通常不做平衡处理。

七、增量训练

在增量训练前，建议先备份原模型：

cp ./best.pt ./backups/best.pt.bak

脚本：incremental_train.py - 功能：加载已有 best.pt 并在新数据上继续训练。 - 常用参数： - --model：预训练模型路径（如 ./runs/classify/incremental_train/weights/best.pt） - --data：数据集配置 YAML（未平衡用 training_tiles_dataset.yaml，平衡后用 training_tiles_dataset_balanced.yaml） - --epochs：训练轮数（建议 20-30） - --lr0：初始学习率（默认 0.001） - --batch：批次大小（默认 16） - --imgsz：输入尺寸（默认 224） - --device：设备（如 0） - --patience：早停耐心（建议 10-30） - 示例：

python incremental_train.py --model ./best.pt --data training_tiles_dataset_balanced.yaml --epochs 25 --lr0 0.001 --batch 16 --imgsz 224 --device 0 --project runs/classify --name incremental_train_new --patience 10

  • 输出：训练日志与权重保存在 runs/classify/incremental_train_new1/。

  • 应用新权重：

cp ./runs/classify/incremental_train_new1/weights/best.pt ./best.pt

八、注意事项（路径与一致性）

  • 路径统一：所有脚本默认使用相对路径，确保在项目根目录运行。
  • 分类命名：仅使用两个类别 zhedang、zhengchang；避免出现其他目录影响训练。
  • 分割与标注：分割阶段可先放入 unknown，标注后应将其清空。
  • 平衡：仅对训练集做过采样，验证集保持原始分布更能反映真实表现。
  • 模型路径：
  • 原模型：./best.pt
  • 新模型训练输出目录与权重由 --project 与 --name 决定。

九、问题排查

  • 摄像头不能打开：检查 /dev/video* 与权限；修改脚本中的摄像头索引。
  • 训练失败：检查 YAML 路径、目录结构（必须包含 train/val/<class>）、GPU 显存。
  • 评估为 None：升级或保持 Ultralytics 版本一致；若 results_dict 键不同，脚本已做兼容处理。

十、示例流程（快速执行）

1) 采集

python continuous_camera_capture.py

2) 分割到 unknown

python split_images_for_training.py --input_dir ./continuous_photos --output_dir ./training_tiles --class_name unknown

3) 标注并归类 ， 用人工浏览training_tiles/unknown/目录，并将图片人工辨别后，根据图片类别分别移动至 training_tiles/zhedang/ 与 training_tiles/zhengchang/ 目录内，完成后删除training_tiles/unknown/目录。

4) 构建 train/val

python prepare_dataset_split.py --input_root ./training_tiles --output_root ./training_tiles_dataset --train_ratio 0.8

5) 训练集平衡

python balance_dataset.py --input_dir ./training_tiles_dataset --output_dir ./training_tiles_dataset --method oversample --split train

6) 增量训练 在增量训练前，建议先备份原模型：

cp ./best.pt ./bakups/best.bak.pt

训练

python incremental_train.py --model ./best.pt --data training_tiles_dataset_balanced.yaml --epochs 25 --lr0 0.001 --batch 16 --imgsz 224 --device 0 --project runs/classify --name incremental_train_new --patience 10

7) 应用新权重：

cp ./runs/classify/incremental_train_new1/weights/best.pt ./best.pt
