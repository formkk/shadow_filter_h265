# CPU 性能对比报告：Intel I7-13700 vs 海光 CPU

**生成时间**: 2026-03-03
**对比项目**: 管道延迟与AI推理性能 (CPU环境)

## 1. 测试环境

*   **基准环境**: Intel Core i7-13700 (本地运行)
*   **对比环境**: 海光 CPU (Hygon)

## 2. 数据摘要 (单位: ms)

基于最近连续运行的性能日志数据进行平均值计算。

| 指标 | I7-13700 (平均值) | 海光 CPU (平均值) | 差异 (ms) | 性能差异 (%) |
| :--- | :--- | :--- | :--- | :--- |
| **平均管道延迟 (Mean)** | 58.46 | 80.49 | +22.03 | +37.67% (更慢) |
| **P95 延迟 (95th%)** | 88.28 | 97.94 | +9.67 | +10.95% (更慢) |
| **最大延迟 (Max)** | 105.84 | 104.80 | -1.04 | -0.98% |
| **平均 AI 推理耗时** | 38.74 | 59.57 | +20.83 | +53.77% (更慢) |

## 3. 详细分析

### 3.1 管道延迟 (Pipeline Latency)
*   **平均延迟**: 海光 CPU 的平均处理延迟为 **80.49 ms**，相比 I7-13700 (58.46 ms) 增加了 **22.03 ms**，性能差距约为 **37.67%**。
*   **稳定性 (P95)**: 海光 CPU 的 P95 延迟较高 (97.94 ms)，比 I7-13700 高出 **10.95%**。
*   **最大延迟**: 两者最大延迟较为接近，海光 CPU (104.80 ms) 略低于 I7-13700 (105.84 ms)，表现出较好的长尾控制能力。

### 3.2 AI 推理性能 (AI Inference)
*   **AI 耗时**: 在纯 CPU 推理环节，I7-13700 优势明显，平均耗时仅 **38.74 ms**，而海光 CPU 为 **59.57 ms**。海光 CPU 的推理耗时比 I7-13700 增加了 **53.77%**。

## 4. 结论

在本次 CPU 性能对比中，**Intel I7-13700 在整体处理速度和 AI 推理能力上显著优于海光 CPU**。

1.  **单核/多核性能差异**: I7-13700 展现了更强的计算能力，平均管道延迟和 AI 推理延迟均大幅领先。
2.  **国产化替代评估**: 虽海然光 CPU 性能较弱，但其最大延迟控制尚可。如果对实时性要求不极其严苛（如允许 ~80ms 的延迟），海光 CPU 仍可作为国产化替代方案，但需考虑 **约 37%** 的性能折损。
3.  **优化建议**: 若必须在海光 CPU 上部署，建议尝试模型量化 (INT8)、多线程优化或使用专用的 NPU/GPU 加速卡来弥补 CPU 算力的不足。
