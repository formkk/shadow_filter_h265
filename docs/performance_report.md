# shadow_filter应用性能对比报告：RTX3090 vs 登临 KS20

**测试时间**: 2026-02-10   
**对比项目**: AI推理性能与管道延迟

## 1. 测试环境

*   **基准环境**: NVIDIA RTX3090 ， patch = 32
*   **对比环境**: 登临科技 KS20 , patch = 2

## 2. 数据摘要 (单位: ms)

基于最近连续运行的性能日志数据进行平均值计算。

| 指标 | RTX3090 (平均值) | KS20 (平均值) | 差异 (ms) | 性能提升 (%) |
| :--- | :--- | :--- | :--- | :--- |
| **平均管道延迟 (Mean)** | 51.79 | 44.85 | 6.94 | 13.40% |
| **P95 延迟 (95th%)** | 71.21 | 63.46 | 7.75 | 10.89% |
| **最大延迟 (Max)** | 102.74 | 70.18 | 32.56 | 31.69% |
| **平均 AI 推理耗时** | 30.29 | 24.31 | 5.98 | 19.74% |

## 3. 详细分析

### 3.1 管道延迟 (Pipeline Latency)
*   **平均延迟**: KS20 平均延迟 **44.85 ms**，比 RTX3090 快了 **13.40%**。
*   **稳定性 (P95)**: KS20 的 P95 延迟优于 RTX3090 (63.46 ms vs 71.21 ms)，降低了 **10.89%**。
*   **最大延迟**: KS20最大延迟 **70.18 ms**，低于 RTX3090 的 102.74 ms，降低了 **31.69%**。

### 3.2 AI 推理性能 (AI Inference)
*   **AI 耗时**: KS20 平均耗时 **24.31 ms**，比 RTX3090 (30.29 ms) 快了 **19.74%**。

## 4. 结论

1.  在平均响应速度、最大延迟控制，AI 推理速度上，KS20 均优于 RTX3090。
2.  KS20 将最大延迟压制在 70ms 左右，极好地消除了 RTX3090 上可能出现的 100ms+ 长尾延时导致的卡顿。  
3.  本应用是基于yolo的图像二分类推理。模型参数规模很小，RTX3090具有10K核心，显存缓存大，适用于大参数大批次推理，对本应用的平衡patch = 32，生产时负载为20%左右。KS20在小批次 patch = 2 时，负载为34%，推理速度快，延迟低，适用于实时场景。  
4.  KS20的延迟低，稳定，可满足实时监控的需求。若进一步优化，如量化到FP16甚至INT8，KS20的推理速度还可以有10-20的预计提升。但如果实施落地应用，还要进行nvenc视频硬件编码在KS20上的移植与性能评估。
